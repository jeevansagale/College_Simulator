# College Simulator

A college life simulation game built in **C++** using **Raylib**. This project is currently in the **very early stages of development** and is being built to learn game programming, software architecture, and gameplay system design from scratch.

The vision is to create an immersive campus experience where players can explore, interact with NPCs, attend classes, complete objectives, and experience student life through a variety of gameplay systems.

## Current Status

> 🚧 **This project is in active early development.**
>
> The current focus is on building the core game framework, player systems, UI, and overall architecture. Many gameplay features are still under development and the project will continue to evolve over time.

* Player movement
